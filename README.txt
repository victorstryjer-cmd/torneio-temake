⚽ TEMAKE & ASSOCIADOS - TORNEIO 3v3 ⚽
=======================================

📋 ESTRUTURA DA PASTA:
├── index.html (arquivo principal do site)
├── imagens/ (pasta para a foto do grupo)
│   └── grupo.jpg (ADICIONE AQUI SUA FOTO)
└── README.txt (este arquivo)

🔧 COMO USAR:

1. Coloque a foto do grupo na pasta "imagens/"
   Nomeie como "grupo.jpg" (ou JPG, PNG)

2. Suba todos os arquivos para o GitHub:
   - Clique em "Add file" → "Upload files"
   - Arraste a pasta inteira "torneio-temake"

3. Ative GitHub Pages:
   - Settings → Pages → Source: main → Save

4. Seu link será:
   https://victorstryjer-cmd.github.io/torneio-temake

✅ PRONTO! O site estará ao vivo!

💡 DICAS:
- A foto pode ser JPG, PNG ou qualquer formato de imagem
- Recomenda-se foto 1200x400px (mais rápido)
- Se a foto não aparecer, verifique o nome do arquivo

❓ PROBLEMAS?
- PDF não baixa? Atualize a página (Ctrl+Shift+R)
- Foto não aparece? Verifique se está em "imagens/grupo.jpg"

Boa sorte com o torneio! ⚽🎉
